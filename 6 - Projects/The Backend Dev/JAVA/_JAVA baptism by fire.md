## 🧭 PHASE 1: Java Primer for WNC Context (1–2 days)

### 🎯 Goal: Read and tweak existing Java code without fear

**Focus on:**  
✅ Classes  
✅ Methods  
✅ Data types  
✅ `if/else`, `switch`, `for`, `while`  
✅ Object-oriented concepts: constructors, inheritance  
✅ How Java handles web apps (controllers, services, models)

### 📘 Do:

- Read: Java for Python Developers (GeeksforGeeks)
    
- Use: [https://www.learnjavaonline.org/](https://www.learnjavaonline.org/) (interactive)
    
- Skim: W3Schools Java Basics
    
- Practice writing a small console program (e.g. todo list, calculator)
