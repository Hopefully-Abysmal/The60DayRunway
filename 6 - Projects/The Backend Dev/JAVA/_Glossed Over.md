|Topic|Why it matters|
|---|---|

|**Type casting** (implicit vs explicit)|Required when mixing types (e.g., `int` to `double`, or `Object` to `String`)|
|Error handling (`try-catch-finally`)|Makes your code robust and safe|

### 📦 Object-Oriented Programming (OOP)

|Topic|Why it matters|
|---|---|
|`class`, `object`, `new`|Foundation of Java's structure|
|Fields vs methods|Know what data an object holds vs what it can _do_|
|Encapsulation (`private`, `public`, getters/setters)|Protects object integrity|
|Inheritance (`extends`)|Enables code reuse|
|Polymorphism & method overriding|Foundation for flexible code|
|Abstract classes & interfaces|Enable clean architecture and plugin systems|
|`this` keyword|Clarifies self-reference in methods|
|Constructor chaining|Needed to design flexible, readable constructors|
