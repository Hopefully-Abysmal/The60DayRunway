### ✅ **Use `[[DEV - object]]` when:**

You're introducing objects as a **data structure or value type**, especially in:

- Scripting languages like **JavaScript** or **Python**
    
- JSON structures (`{ key: value }`)
    
- Situations where objects are used as flexible containers (without OOP design)
    
- Comparing with arrays, maps, or primitives
    

📎 _Think: “What is an object in code? How do I use it to hold data or group things?”_
