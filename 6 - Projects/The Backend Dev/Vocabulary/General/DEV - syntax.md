# [[DEV - syntax]]

## 🔍 Definition  
**Syntax** refers to the **set of rules** that define the structure of code in a programming language — how statements, expressions, and symbols must be arranged to be valid and understandable by the compiler or interpreter.

## 🧠 Key Points  
- Like grammar in a spoken language.
- Syntax rules **vary by language** (e.g., Java uses semicolons, Python uses indentation).
- Syntax **errors** (a.k.a. parse errors) prevent code from compiling or running.

## ✅ Examples

### Java
```java
int x = 5;      // Correct syntax
int x 5         // Incorrect syntax (missing '=' and semicolon)
````

### Python

```python
x = 5           # Correct syntax
x == 5          # Valid expression, but not an assignment
```
