# [[DEV - statement]]

## 🔍 Definition  
A **statement** is a single **instruction or command** that the computer can execute. It is the **smallest standalone unit** of execution in a program.

In most programming languages, statements perform actions like:
- declaring variables
- assigning values
- calling functions
- controlling flow (e.g., `if`, `for`, `return`)

---

## 🧠 Key Points  
- Statements usually **end with a semicolon** in languages like Java, C, or JavaScript.
- They **do not return values** (unlike expressions).
- A **block of code** is a collection of one or more statements wrapped in `{}` (Java) or indented (Python).

---

## ✅ Examples

### Java
```java
int score = 90;           // variable declaration & assignment statement
System.out.println(score); // method call statement
````

### Python

```python
score = 90               # assignment statement
print(score)             # function call statement
```
