# [[DB - database]]

## 🔍 Definition  
A **database** is a structured collection of data that is stored electronically and can be accessed, managed, and updated efficiently.

> In essence: a digital filing system optimized for storing and retrieving structured information.

---

## 🧠 Key Points  
- Stores data in tables, documents, graphs, or other models depending on the database type.
- Enables efficient querying, updating, and managing of large datasets.
- Can be relational ([[DB - SQL|SQL]]) or non-relational ([[DB - NoSQL|NoSQL]]).
- Supports indexing, constraints, relationships, and permissions.

---

## ✅ Examples

```sql
-- Creating a new database (PostgreSQL)
CREATE DATABASE my_project_db;

-- Selecting a database (MySQL)
USE my_project_db;
````

> A database may contain multiple tables with foreign key relationships and is accessed via [[DB - SQL|SQL]] or [[DEV - API|API]] layers like Supabase.

---

## 📚 Real-World Use Cases

- Used when building applications that need to persist user, product, or transaction data.
    
- Helps ensure data consistency, integrity, and efficient access.
    
- Common in systems like PostgreSQL, MySQL, MongoDB, Firebase, and Supabase.
